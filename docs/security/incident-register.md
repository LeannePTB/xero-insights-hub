# Incident register

Every security or privacy incident is recorded here, however small. An empty
register with a clear format is better than no register; an assessor will ask
for it. Related: [incident-response.md](./incident-response.md).

## What counts as an incident

- Unauthorised access to, or disclosure of, any client or personal data.
- A lost or stolen device that was signed in.
- A credential, token or secret exposed anywhere it should not be.
- A bug that showed one organisation another organisation's data.
- A sustained outage affecting access to client data.

## How to record one

Add a row to the table below and a short entry underneath with: what happened,
when it was discovered, how it was discovered, what data was affected, what was
done, who was notified (clients, OAIC, Xero), and what changed so it cannot
happen again.
